Інтерактивний аналітичний дашборд у Power BI для аналізу ефективності телефонних дзвінків, генерації лідів та продуктивності менеджерів.

Дашборд дозволяє аналізувати:
- Інтенсивність дзвінків по годинах
- Розподіл лідів по днях тижня
- Порівняння ефективності менеджерів
- Аналіз робочого та неробочого часу
- Середню швидкість обробки дзвінків
- Статуси дзвінків (співставлено / не визначено)

📅 Період аналізу
01.06.2023 – 30.09.2023

📊 Основні метрики
- Calls Count (кількість дзвінків)
- Leads (ліди)
- Leads %
- Avg Speed (середня швидкість)
- Call Status
- Робочий / неробочий час

⚙ Функціонал
✔ Динамічна фільтрація за:
- періодом
- напрямком виклику (in / out)
- менеджером
- днем тижня

✔ Heatmap-таблиця для порівняння менеджерів
✔ Графік інтенсивності дзвінків по годинах
✔ Donut-діаграма розподілу лідів

🛠 Використані інструменти

Power BI
DAX
Power Query

Дашборд допомагає:
- Визначити пікові години навантаження
- Проаналізувати ефективність менеджерів
- Виявити вплив неробочого часу на ліди
- Оптимізувати розподіл робочого часу
